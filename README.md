# Duttern Consultant - Responsive UI Mockup

A minimalist, high-converting front-end platform built for a fictional South African IT infrastructure firm based in Midrand. 

## 🔗 Live Demo
[Click here to view the live responsive project](https://github.com/matetemagomane/duttern-consultant-mockup)

## 🛠️ Features & Tech Stack
- **Languages:** Semantic HTML5, Vanilla JavaScript, Custom CSS3 Variables.
- **Interactivity:** A dynamic, interactive team organization chart utilizing responsive JS event listeners to display specific role insights on hover.
  
- **Design System:** Engineered with a cohesive, professional deep navy and high-energy tech-teal color palette optimized for modern corporate branding.
- **Performance:** 100% template-free, lightweight architecture ensuring instant loading speeds and fluid animations.
